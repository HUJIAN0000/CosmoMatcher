# Manuscript-to-code map

| Manuscript item | Code / frozen output |
| --- | --- |
| 161-lens/Pantheon+ matching, physical IDs, covariance blocks | root `CosmoMatcher.py`, `reproduce.json`, `reference_results/` |
| Constraint matrix / covariance / yield figures | `paper_figures/` (adopted PDFs), root reference arrays and main backend plotting |
| Known-truth Figures 5–6 and simulation tables | `benchmarks/stress_results/`, `make_paper_figures.py` |
| Observed constant/linear GLS comparison | `benchmarks/reproduce_observed_gls.py`, `observed_results/` |
| Scientific application section | `applications/cddr143_application/scientific_application.tex` |
| Figure 7 overlay and Figure 8 comparison | application `output/`, regenerated by `make_outputs.py` using saved samples |
| CDDR parameter table | application `output/parameter_constraints.csv`, same two runs as Figures 7–8 |

The authoritative full manuscript is in the sibling `1_LaTeX_submission` folder. This code repository intentionally excludes the full manuscript, editorial correspondence, author-only funding notes, marked manuscript, local backups and exploratory cddv302 analyses. The extracted application section includes the current historical motivation and inference limitations.

`paper_figures/` contains the eight exact PDF figures included by the submitted LaTeX source. The application TeX is a reference excerpt, not a standalone document.

A sixth companion application, accepted by RAA (arXiv:2610.26097), documents lens--quasar--cluster use. It is cited, but its separate scientific pipeline is not included or independently reproduced here.
